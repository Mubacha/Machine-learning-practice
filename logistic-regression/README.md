# Logistic Regression Practice

This project demonstrates a basic binary classification workflow using logistic regression in Python with scikit-learn.

## Objective

Practice the fundamental steps involved in building and evaluating a logistic regression model.

## Workflow

1. Load a dataset.
2. Split the data into training and testing sets.
3. Standardize the input features.
4. Train a logistic regression model.
5. Generate predictions on the test set.
6. Evaluate the model using accuracy, a confusion matrix, and a classification report.

## Dataset

The project uses the **Breast Cancer Wisconsin dataset** provided through scikit-learn's built-in datasets.

## Tools

- Python
- scikit-learn

## Files

- `logistic_regression.py` — Python script containing the complete workflow.
